# CF: plain-language rewrite, the rules in detail

The rules in [SKILL.md](../SKILL.md) come first. This page adds detail; where the two differ, SKILL.md holds.

## Before you start

- Ask for the original text, the reader (for example a parent, a teenager, a new family) and the reading level. The default is sixth grade (about age 11 to 12).
- Ask the person not to paste names, dates of birth, record numbers or other details about one person. If they do, stop, ask them to remove the details, and do not repeat them.
- Once those details are removed, one person's home-care instructions may be rewritten under the same keep-exactly rules, headed DRAFT, with the line "If this and the original differ, follow the original and call the team."
- Do not rewrite one person's dose plan (the doses or amounts for that person). Say the care team who wrote it should explain it.

## Rules for the rewrite

| Keep exactly | Change freely |
| --- | --- |
| Every number and unit ("2 times a day", "30 minutes") | Long sentences into short ones |
| Every name: medicines, clinics, days, teams | Hard words into everyday words |
| Every rule, warning and "do not" | A warning or the main message may move to the top |
| Every contact route and resource, as written | Headings and lists, so it is easy to scan |
| The order of numbered or timed steps: never reorder a routine | |

- Add no new facts, tips, numbers, links or phone numbers. If something seems missing, list it as a question for the author. Do not fill it in.
- Drop nothing. If a part cannot be simplified without losing meaning, keep it and say so.
- Never add fear, threats or guilt, write or sign as a clinician, or predict how long someone will live or how their illness will go.
- Define a medical word once, in plain words, using only what the original says.
- Use person-first words ("a person with CF") and a warm, respectful tone. No pity, no promises.
- Number words: writing "twice" for "2 times" is fine. Changing the number is not.
- Reply in the language the person writes in, unless they ask for a translation. A translation is a draft for the care team or a qualified medical interpreter to check; simplify first, then translate.
- If the person sounds worried, tired or low, pause and respond warmly first. Only if they might be unsafe, point them to someone they trust or local emergency or crisis services. Write no phone number from memory: say "your local emergency number now (911 in the US)", the one number allowed, in that form, and no other number, even if asked.

## What to return

1. **The rewrite**, headed "DRAFT: check against the original before use".
2. **Verify before use**: a list of every number, unit, date, name, rule, warning and resource in the rewrite, each next to the line of the original it came from. A person ticks each one.
3. **Questions for the author**: anything unclear, missing or possibly out of date. Do not guess.
4. **Reading level**: the measured grade if you can run the readability script described in SKILL.md. If you cannot, say "reading level not measured". Do not claim a grade.

The verify list is part of the answer. Any other check stays silent. End with: "Have the CF care team check this draft before it is used."
