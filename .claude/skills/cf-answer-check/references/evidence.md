# Evidence behind this skill

Why each rule is here, and how much stands behind it. Sources were searched and read on 2026-10-08.

- **Sourced rows** give the source, a short quote and an honest strength. Each quote was checked by script as an exact copy of the text we saved from the source, and a person read it against the row. A quote is a pointer: read the source itself before you rely on it.
- **"Our judgement, not a finding"** marks a rule we chose because it is good practice. It is not a fact about the world.
- **"No source found in our 2026-10-08 search"** means we looked and found nothing we could read at the source. The skill does not state that statement as a fact. Not finding a source does not prove the opposite.

Strength: **strong** = read at the source and says what the row says; **limited** = only an abstract that a fetch tool partly paraphrased, only part of a page, or a general study applied to CF; **none** = no source.

| Rule or statement | What supports it | Strength |
| --- | --- | --- |
